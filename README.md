# jsanchez_libs

A collection of small **C/C++ libraries and tools** developed for game programming and systems-oriented projects.

## Features

* **Generic dynamic array**
* **Game math library**

  * 2D and 3D vectors
  * Column-major matrices
  * Math helper functions
  * Unit tests
* **Linear memory allocator**
* **Asset embedding tool**

  * Statically embeds assets into an executable
